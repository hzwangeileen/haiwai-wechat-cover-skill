# One-shot 使用指南

## 1. 安装

把以下 GitHub 目录链接发给 Codex：

```text
https://github.com/<OWNER>/haiwai-wechat-cover-skill/tree/main/skills/haiwai-wechat-cover
```

然后发送：

```text
请安装这个链接里的 Skill。安装完成后，使用它处理我接下来上传的素材。
```

## 2. 最小输入

用户只需要提供：

1. 一张图片；
2. 一个中心关键词，或一个透明背景的公司 Logo。

示例：

```text
使用 haiwai-wechat-cover。
图片见附件。
中心关键词：Agent Identity。
```

## 3. 可选控制

```text
强调词：AI
强调色：#B51F2A
其余文字：自动黑/白
必须完整保留：人物、产品、图表、原图文字
Figma 文件：https://www.figma.com/design/...
```

## 4. 默认交付

Skill 应一次性返回：

- 900 × 383 横图；
- 900 × 900 方图；
- 1307 × 383 组合预览；
- 三种文件的 2× 高清版；
- Figma 工作区与三个 Frame 的直接链接；
- 实际使用字体及替代字体说明；
- 使用了裁剪、画布延展或元素重组时的简短说明。

## 5. 质量判断

成品必须同时满足：

- 中央关键词或公司 Logo 清晰且视觉尺度一致；
- 主体完整，不是把整张素材机械缩小后塞进角落；
- 原图的字体、产品、Logo、图表、材质和光影没有被重画；
- 横图和方图可采用不同构图；
- 蒙版边缘与背景接缝不可见；
- 标准版与 2× 版尺寸准确；
- 海外独角兽 Logo 位置、比例和对比度正确。
